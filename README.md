Student Attendance Management System

A simple web-based system for managing students and their attendance.

Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

Features

- Admin Login
- Student Management
- Daily Attendance
- Attendance History
- Attendance Reports
- CSV Export
- Dashboard
- Change Password

Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project to "htdocs".
4. Import "database.sql" into MySQL.
5. Open the project in your browser.
